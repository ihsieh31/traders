# Exhaustive GitHub search: US equity data for DELISTED / ACQUIRED / MERGED / BANKRUPT companies

**Compiled:** 2026-09-28 · **Method:** `gh api` repo + code search (≈60 repo queries, ≈20 code queries), followed by direct file inspection (`git/trees`, `contents`, raw downloads, HTTP-range extraction from release ZIPs). Every claim in Tables 1–2 was verified by opening the actual files, not by reading the README.

## TL;DR

1. **No free GitHub repo contains a full point-in-time US equity universe with prices for dead names.** Everything that exists is *S&P 500 / Nasdaq-100 membership only* (~800–1,200 tickers ever), not the full market (~13,000–15,000 names for 1999–2026).
2. **The single most valuable artifact found** is [`teddykoker/survivorship-free-spy`](https://github.com/teddykoker/survivorship-free-spy) — 641 per-ticker daily OHLCV CSVs where prices genuinely run *to the last trading day before delisting* (verified on WFM: ends 2017-08-28, the exact delisting date). 118★. Limitation: 2006–2019, S&P 500 only, **no license file**, and no delisting return.
3. **`fja05680/sp500` (947★, MIT)** is the canonical index-membership repo. **But it has real holes** — LEH, Enron, Fannie, Freddie, Ambac are *absent* (author admits the 1996–2005 seed has only 487 symbols). Two smaller repos fill those gaps.
4. **qlib's `instruments/all.txt` does NOT solve this.** I extracted it from the release ZIP via HTTP range requests: the US list is 8,994 tickers all ending on the dataset cut date (2020-11-10) — a live universe scrape. **However**, qlib's `instruments/sp500.txt` and `nasdaq100.txt` *do* carry real membership end-dates (250 and 238 removed names respectively) and DO contain LEH/ENRN/FNM/FRE/ABK in the membership file.
5. **LEAN models delisting correctly but does not ship the data.** `Algorithm.Python/DelistingEventsAlgorithm.py` says verbatim: *"This data is not included in the open source project."*
6. **The only fully free + live + official delisting registries I could verify are Chinese**: `akshare.stock_info_sh_delist()` (159 rows) and `akshare.stock_info_sz_delist()` (208 rows) — I called both endpoints and they return real data with delisting dates through 2026-07.
7. **A large fraction of search hits are AI-generated slop** (empty READMEs, marketing-only repos, or code with a `max_market_cap` filter that was never applied). See Table 3.

### Table 1 notes

- Rows 2–6 are **complementary, not redundant**. The practical move is to union `gylu` (2000–2026, fills 2008 GFC) + `lawcal` (adds CIK) + `riazarbi` (adds ISIN/SEDOL/CUSIP) and treat `fja05680` as the pre-2000 base with known holes.
- **None of these give you a delisting *return*.** Every one stops at the last price. CRSP's `DLST_RET` convention (typically −55% to −100% depending on methodology) is not reproducible from any of these. Searched `DLST_RET` across all of GitHub: **1 hit**, and it is a false positive in a C# PowerPoint library.
- **No free repo merges the membership table with prices for dead names**, except `teddykoker` (2006–2019, S&P 500 only) and qlib (166 names, 1999–2020).

## Recommended path for the researcher

The honest answer to "is complete delisted data hidden in some backtesting tool" is **no** — but there is a good 80% free reconstruction for **large-cap US equities**, assembled from four repos that I verified are complementary:

```
lawcal/sp500-components-history   →  membership + CIK + date_added/date_removed   (2007–2026, 499 removed)
gylu/sp500_companies_since_2000   →  monthly snapshots 2000–2026, 837 tickers     (fills LEH/FNM/FRE/ABK gap)
fja05680/sp500                    →  1996–2026 base, 1,209 tickers, 706 departures (has holes pre-2005)
riazarbi/sp500-scraper            →  ISIN/SEDOL/CUSIP/CIK identity resolution   (2006–2026, live)
        │
        ├── prices: teddykoker/survivorship-free-spy  (641 OHLCV CSVs, 2006–2019, to real delisting date)
        │           qlib_data_us_1d_latest.zip        (166 dead-name .day.bin series, 1999–2020)
        │           Norgate Data (paid — the only vendor fja05680's own author endorses for this)
        └── delisting return:  YOU must apply it. Nothing on GitHub has it.
```

**What genuinely does not exist for free anywhere on GitHub:**
- A full-market (not index) point-in-time US universe — closest free proxies are Polygon/NasdaqTrader live lists, which are survivorship-biased by construction.
- Delisting **returns** (CRSP `DLST_RET` convention). Not one repo.
- Prices for small/mid-cap delisted names. `teddykoker` + qlib together cover roughly **250–300 dead large-caps** out of the ~3,000+ US delistings since 1999 — call it ~8%.
- Anything before 2000 outside of `fja05680`'s incomplete 1996–2005 seed.

**Cheapest legitimate supplements** (all verified reachable, none free): **Norgate Data** (referenced by `fja05680`'s own author as the correct source for "delisted and changed symbols in the S&P 500 history"), **Sharadar SF1/SEP** (`tenicho/data-cleaning` shows the exact recipe), **Tiingo** (the free tier backs delisted prices — what `K0D1Z` uses), **CRSP via WRDS** (the only source with proper `DLST_RET` + reason codes).

**Free delisting registry for any US security, if you don't want a vendor:** SEC EDGAR Form **25** (exchange delisting) and Form **15-12G/15-15D** (voluntary deregistration), full-text search via `efts.sec.gov`, gives you ticker/CIK/date/form for free. `antoinesavelli`'s scraper is a working skeleton (fix the ticker→CIK resolution and drop the market-cap filter), and the paid `BlackFalconData` Apify actor is the same idea with the mapping already done.
