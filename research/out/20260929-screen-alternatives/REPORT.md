# 五個替代初篩方案：偏穩定公式與基本面方向

本次使用者問有沒有更好的公式或篩選方法。結論：有一個**在這份價量樣本中
更偏向減少短期大跌**的方案，但沒有任何新方案在兩期都同時降低大跌率、
保住大漲比例。若垃圾指公司品質，改用基本面資訊較貼合目標，不能由價量
研究認證。生產程式、原報告與原審查均未修改。

## 2. 偏穩定的候選公式

目的：在固定20個分析名額內優先分析價格走勢較平順、流動性較好的候選。
不是用來找短期大漲股或認證公司健康。

先過既有資格，額外 keep：

```text
vol20 <= 0.45                  # 最近20日總波動，年化上限45%
r60 > 0                        # 最近60日報酬為正
dd60 >= -0.25                  # 當前close相對最近60日最高close不跌超過25%
```

指標與分數：

```text
ER60 = log(close[t]/close[t-60]) / sum(abs(最近60日日log return))
D20  = sqrt(252 * mean(min(最近20日日簡單報酬, 0)^2))
S    = (p_keep(ER60) + p_keep(ADV20) + 1 - p_keep(D20)) / 3
```

ER60 是有方向的價格路徑效率，順暢上漲接近1，來回震盪接近0。D20 使用
全部20日作分母，上漲日以0計入。所有百分位在各日存活池內重算，取分數
最高的最多20檔，並列依symbol。零變動路徑ER設0；無完整歷史／缺數據不入選。

相對原報告，20日內大跌率差為 -4.74／-3.31 個百分點，3期區塊、2000次
bootstrap的95% CI分別是 [-7.59, -2.59]／[-5.48, -1.29]。本輪五個方案及
先前歷史搜尋未做多重檢定修正，這是探索性區間，不能稱正式確認。

資歷可用後每天的存活池最低18／83檔，原報告是9／16檔。不足20的天數
減為1／0，**仍不保證任何未來交易日都有20**。表中機會成本也很明確：
大漲比例從6.90／8.39降至3.10／4.60。若仍重視大漲候選，不能將此方案
稱全面較好。它也不能攔下所有崩跌。

## 3. 若「爛」是公司品質，建議改資料與流程

先由程式批次過濾資產資格、流動性、公開破產／違約事件與資料可得性，
再計算基本面品質分數，最後取最多20才交給LLM。

一個**尚未在本專案回測**的最小非金融企業候選式是：

```text
Q = [p_sector(毛利TTM / 平均總資產)
   + p_sector(營業現金流TTM / 平均總資產)
   + p_sector(-(有息負債 - 現金) / 總資產)] / 3
```

同產業百分位避免天然不同的資產／利潤結構直接互比；金融與REIT需要
另外的會計口徑，不能直接套用。負現金流、負淨值或較高槓桿是需要判斷的
特徵，不能因單一指標就把成長公司或回購公司一概認定為垃圾。
Q只決定固定分析預算內的優先序，不代表合理估值、不保證賺錢。

這個方向的依據：Novy-Marx研究毛利／資產品質；Asness、Frazzini與Pedersen
的Quality Minus Junk研究獲利、成長、安全等品質資訊。這些是**因子方向的
外部研究證據**，不是本簡化Q權重／20檔名單的驗證，也不能直接外推為20日效果。

- [Novy-Marx: The Other Side of Value](https://www.nber.org/papers/w15940)
- [Asness et al.: Quality Minus Junk，期刊論文](https://link.springer.com/article/10.1007/s11142-018-9470-2)
- [作者的研究說明](https://www.aqr.com/Insights/Research/Working-Paper/Quality-Minus-Junk)

SEC提供免費、無API key的companyfacts／filing JSON，也有每晚更新的批次
下載，適合用程式更新數字，這不需要對每家公司呼叫LLM：
[SEC EDGAR APIs](https://www.sec.gov/search-filings/edgar-application-programming-interfaces)。
回測必須按實際公布時點截斷，不能把後來重編的財報回填到早期。只有公布
日期時要採保守可得時間；TTM要正確拆解累計季度值。缺資料列未知，不能
當成通過，也不能自動改用LLM去補到突破20個名額。

本地已有SEC filings metadata helpers，但不是本次需要的全市場歷史數值
面板。本次沒有抓取財報、沒有建立Q回測，因此不提供虛構的績效。

## 4. 選用判斷

- 只用現有價量，優先少碰短期大跌：可先凍結第2節公式作候選，下一段
  未使用樣本再測；不得把它標為已驗證基本面品質。
- 仍要更多大漲機會：新測試沒有找到跨兩期全面勝過報告的公式；下行波動
  版本增加了大漲，也增加了大跌。保留原方案當對照。
- 真正要排除困境／低品質公司：投資基本面批次資料，第3節Q為待測起點，
  不靠反覆微調vol20門檻來冒充公司品質。
- 無論哪條路，程式直接選最多20，LLM之前去重、扣持倉名額及驗收預算。

兩個歷史時段都已使用，本次無未使用驗證集。研究池還可能含ETF，缺少
歷史市值／資產分類與死亡股標籤，不能說這就是普通股生產池的效果。
各入選路徑的未知數本次均為0，但不代表宇宙沒有存活者偏差。
