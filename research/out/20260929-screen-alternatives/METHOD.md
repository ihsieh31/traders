# 固定五個替代初篩方案，再看結果

使用者問有沒有更好的公式／方法。本次仍為離線歷史探索，2016–2020 與
2021–2025 均已被使用，不能當成獨立驗證集。不改生產、不呼叫 LLM 或券商。

固定對照 `current20`、`report28`、`reuse28`，新增以下五個方案，全部公開，
不根據結果追加權重、門檻、變體或重新挑年份。

所有 keep 先通過既有研究 eligibility；指標全部 trailing。百分位母體是
各方法存活池。若不足20，輸出實際數量，不增加不合格股票。研究 qualification
仍缺歷史市值、歷史普通股分類／財報／破產狀態，不能認證基本面垃圾排除。

## 指標

- down20 = sqrt(252 * mean(min(日簡單報酬, 0)^2))，20日年化向下半偏差，
  上漲日以0計入20日分母；不是只對下跌日求標準差。
- dd60 = close / max(close[t-59:t+1]) - 1，只量當前離60日最高收盤有多遠。
- ER60 = log(close/close[t-60]) / sum(abs(60日log return))，有方向的路徑效率。
- p_cs 用平均名次百分位；score 並列依 symbol 排。

## 五個方案

1. `down20`：down20 <= .20、trend > 0、r60 >= -.25，存活池原有分數取20。
   目的：不把所有向上跳漲都算成要剔除的風險。
2. `down20_dd60`：第1式再加 dd60 >= -.25，原有分數取20。
3. `efficient60`：vol20 <= .45、dd60 >= -.25、r60 > 0；
   score = (p_cs(ER60) + p_cs(ADV20) + 1 - p_cs(down20))/3，取20。
4. `relative80`：在當日原資格池 p_cs(vol20) <= .80，再加 dd60 >= -.25、
   r60 >= -.25；存活池原有分數取20。目的是避免市場整體波動升高就只剩幾檔。
5. `core15_plus5`：原 .28 門檻＋原分數取最多15；再从 down20方案取最多5，
   排除已選股票。兩區若不足不跨區偷補，最多20。

## 衡量

沿用上次review的日期、次日open入場與20日close路徑。前瞻缺價保留unknown。
主指標bad_path10＝20日內任一close較入場跌至少10%；up_end10＝20日期末
漲至少10%。同時報bad_path20、期末跌10%、未知數與個股前瞻波動。
逐方法報所有排定日與實際選取數；配對風險／上漲差只用兩方法都恰有20的
共同日期。不能把不足20的日期算成零風險來改善結果。

block bootstrap 按日期期間群組，block=3期間、2000次、seed=20260929。
全部比較均為探索性，區間不校正歷史參數搜尋與本輪五個方案挑選。

「觀測上更好」必須大跌率不增、期末大漲率不減，且兩時段都成立。
如果沒有方案做到，就明確回報沒有找到，不把降低兩邊機會的方案說成全面改善。
觀測支配也不是統計確認；共同日期太少、價格路徑或公司品質未知另揭露。

若基本面方案無可用歷史面板，只能提出有文獻基礎的待測規格，不能填造本地成績。
