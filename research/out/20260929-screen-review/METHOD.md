# 篩選報告獨立核對：事先固定的量測規格

這是使用者要求的報告審查與離線證據，並非生產變更或新 alpha 搜尋。
本文件在本次計算結果產生前寫下。所有方法沿用已被原研究查看過的資料，
2016–2020 與 2021–2025 都是歷史診斷，後者不能再稱獨立 holdout。

## 固定比較

1. `current20`：原有 production_score，原有資格池取 20。
2. `report28`：報告的 vol20 <= 0.28、trend > 0、r60 >= -0.25，
   然後 0.5*p(trend) + 0.3*p(r60) + 0.2*(1-p(vol20)) 取 20。
3. `reuse28`：相同硬門檻，沿用 production_score（百分位以存活池計），
   取 20。不另發明填充分數；這只是最低工程成本的替代方案，非優化解。
4. 額外對照全部 eligible、keep 與 removed，驗證門檻是否降低壞結果機率。

不改門檻、不掃參數、不選最佳子期間。只讀本地 bars/calendar，禁止任何
網路、LLM、券商呼叫。使用既有 trusted universe；目前缺乏歷史市值、
當時資產資格與財報/破產標籤，必須保留此限制。

## 時間與結果定義

- 每期 20 個交易日，as_of 從指定年份的第一個交易日開始，每 20 日取一次，
  完整前瞻窗口必须落在該時段。領先資料僅用於特徵，不可算入測試時段。
- 入場：t+1 open；出場：t+20 close。
- `bad_end10`：出場相對入場 <= -10%。
- `bad_path10`：未來 20 日任一日 close 相對入場 <= -10%。這是收盤觀測
  的不利價格變動，不是 intraday 最低價或高點起算回撤。
- 缺失入場、出場或任一日 close => unknown，不能當成安全或事後刪掉。
  報告風險率的下界（已知壞/原選取數）與上界（已知壞+unknown/原選取數）。
- 同時報 +10% 期末機率與報酬離散度，揭露風險縮減的機會成本。
- 前瞻波動仍照原定義計算，但明確標為個股波動中位數。
- 配對差的信賴區間：按 20 日日期群組做 moving block bootstrap，
  3 個期間一區塊（約 60 日）、2000 次，固定 seed 20260929。
  額外報 block=1/6 的敏感度，不將股票視為獨立樣本。
- 重現原報告的錯誤採樣方式，以核對數字；正式比較改用正確年份起點。
- 基本自測涵蓋相同歷史下的 prefix invariance、20 檔去重與持倉預算分配。

不能以「存活池大」驗收垃圾股排除。不能以此診斷宣稱基本面品質、
未來獲利、LLM 實際決策改善，或已通過獨立策略驗證。
