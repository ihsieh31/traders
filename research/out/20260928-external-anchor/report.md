| 問題 | 我們量到的 | 同期間外部真值 | 倍數 |

| 2016–2023 | +9.0%（t=1.46） | −1.47%（t=−0.22） | 符號相反 |

| 2020–2025 | +13.7%（t=2.38） | +2.70%（t=+0.32） | 5.1× |

**CRSP（1926–2026，含全部死亡股）在 2016–2025 的每一個子區間，
長端動能年化都在 −1.85% ~ +2.70% 之間，t 值全部 |t| < 0.4。**
同期我們的 harness 量到 +9.0% ~ +17.9%，t = 1.46 ~ 3.76。

**這不是「量錯了大小」，是「在效應不存在的窗口裡量出了效應」。**
在效應真實為零的窗口上，任何掃描都會出現隨機峰值——這正好解釋
為什麼 55 日是「尖峰」、剔除最佳 5% 就翻號、DSR 極低。

## 4. 過度擬合：Deflated Sharpe Ratio

`purgedcv` 對 18 個組合作 DSR（GuKelly/Jiang/Barclay 2020）：

| 項目 | 值 |
|---|---:|
| 最佳 SR（生產公式 @ 90 日，n=12） | 0.970 |
| `effective_n_trials`（purgedcv 的估計） | 8 |
| DSR，n=18 | 0.369 |
| DSR，n=8 | 0.582 |
| DSR，n=588（全部歷史輪次） | **0.021** |
| PSR(SR > 0) | 0.9864 |

**PSR = 0.9864 只說明「這個樣本內 SR 統計上大於 0」，
不說明「效應存在」**——這正是 DSR 要處理的問題。
在 n=588 時 DSR 掉到 0.021。

而 §2 的外部真值說明：同期真實動能 SR 是 **−0.100**。
我們量到 0.92，**符號都錯了**，任何 DSR 都不該是高的。
兩者一致地指向「這是雜訊」。
