# 做空篩選：評估前固定規格

本檔先於結果建立。這是已被多次研究過的 2016–2020 探索樣本；不是獨立驗證，也不選用 2021–2025 的報酬來調參。只新增本目錄檔案，不修改其他研究或正式交易路徑。

## 問題與邊界

找出最多 20 個值得做空研究的標的，並量測追空後反彈的風險。OHLCV 只能判斷價格弱勢，不能證明公司品質差。另查 Beneish M-score 的原始文獻，作為財報品質的獨立候選；本地沒有可重建歷史申報時點的完整財報面板，因此不偽造 M-score 回測。

沿用本地 trusted_symbols 與 61 根完整交易日、價格 >= $5、ADV20 >= $20M 的資料門檻。本地沒有歷史市值、歷史公司/ETF 分類、借券、召回、股息補償或完整下市結算資料。trusted_symbols 與快取均有存活及覆蓋偏差風險。不得宣稱這些結果代表所有公司或可實際借券的公司。

## 固定四種方法（禁止看結果後新增或調參）

`p(x)` 為當日橫斷面升序百分位，平均排名處理平手，單一標的為 0.5。每種方法依分數降序、symbol 升序選最多 20；不足不補不合格股票。價格門檻通過後的集合記為 U。

1. **legacy_short_proxy**：`trend < 0 AND (r20 < 0 OR r60 < 0)`；分數為 `100*[.20*p_U(ADV20)+.25*(1-p_U(r20))+.25*(1-p_U(r60))+.15*(1-p_U(vol20))+.15*p_U(volume_ratio)]`。這是正式程式負向候選 lane 的確定性代理，沒有重演 LLM 選股、產業配額或成交。
2. **mirror28**：U 加 `vol20 <= .28, trend < 0, -.25 <= r60 < 0`；僅在倖存集合 V 排名，`100*[.50*p_V(-trend)+.30*p_V(-r60)+.20*(1-p_V(vol20))]`。測試原多頭公式反向後是否有效。
3. **bounded45**：U 加 `vol20 <= .45, trend < 0, r20 < 0, -.25 <= r60 < 0`；分數同 mirror28。避免只追暴跌標的；.45 與 -.25 是預先固定的研究假設，不是論文證實的最佳門檻。
4. **efficient60**：门檻同 bounded45；`ER60 = log(C_t/C_{t-60}) / sum_{i=t-59..t}|log(C_i/C_{i-1})|`；分母零則 0。`up20 = sqrt(252 * mean(max(daily_return,0)^2,20))`。分數 `100/3*[p_V(-ER60)+p_V(ADV20)+1-p_V(up20)]`，偏好持續下跌、流動性及較小上行波動。

`trend=C/MA20-1`；`r20,r60` 為相應交易日簡單報酬；`vol20` 為日報酬 20 日樣本標準差乘 sqrt(252)。計算只使用截至訊號日的資料。

## 固定量測

- 訊號日最早須有 61 根資料；訊號收盤後排名，下一交易日開盤進場、第 20 個交易日收盤退出。訊號與進出場全部限定 2016–2020；每隔 20 個交易日取一個訊號，不重疊。固定單一 20 日 horizon，所有四方法全部報告。
- 單檔做空價格報酬 `1-exit/entry`；不能用 `entry/exit-1`，不截斷虧損。若每檔配置總本金 1/20，未選足名額留現金，不加槓桿補滿。
- 股价逆向上漲風險用進場日至退出日 **daily high** 的最大值 / entry - 1，報告 >=10%、>=20%；終點下跌 >=10% 是獲利機會。這不是有停損的績效回測。
- 缺失退出價格不當作獲利、不補零、不剔除後聲稱完整策略績效：該整期投組收益標記未知。缺失 high 的風險區間報告已知事件率及「所有未知都出事」的上界。
- 成本情境為固定 round-trip .1% 和 .2%，加年化借券費 0%、5%、20% × 實際曆日/365，按初始放空名目收費，屬簡化壓力情境；真實借券費可能按每日市值、變動費率與券源重算，股息、召回、融資尚未計入。
- 按年度與全期報告；未知整期明列。平均投組單期報酬、Newey–West lag=1 t 值為探索診斷；95% 循環 block bootstrap（block=3 期，2000 次，seed=20260929）僅作不確定性描述，沒有多重比較校正，不是驗收門檻。比較新方法與 legacy 只用雙方完整且均選足20檔的同日訊號。
- 基準另列每個訊號日 U 的等權做空報酬（大量標的的比較用診斷，非可交易投組）。只跑本地快取，禁用研究程式網路及 LLM。

## LLM 預算的實作含義

此處各方法的 Top20 是獨立診斷。正式整合須先保留既有持倉風險審查名額，再由多空候選分配剩餘名額，最終唯一 symbol 聯集 <=20。不能多頭20再加空頭20。若合格做空標的不足，允許少於配額或不做空。這次研究不會將未驗證方法寫入正式交易程式。

## 計算正確性檢查

固定例：100→90 的做空報酬為 +10%；100→110 為 -10%；100→250 為 -150%。測試 high 能捕捉收盤未反映的反彈、缺失終價使整期未知、價格公式前綴不變、平手和預算上限，以及 legacy score 與 production 的負向 lane 一致。
